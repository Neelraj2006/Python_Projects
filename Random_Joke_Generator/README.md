# Random Joke Generator

A simple Python project that fetches a random joke from the internet using an API.

This project marks my first step into working with **APIs**, **JSON**, and the **Requests** library in Python.

## Features

* Fetches a random joke from a public API
* Displays the joke setup and punchline
* Uses HTTP GET requests
* Parses JSON responses into Python dictionaries
* Handles API request failures gracefully

## Technologies Used

* Python 3
* Requests Library
* JSON
* REST API

## Requirements

Install the Requests library:

```bash
pip install requests
```

## ▶️ How to Run

1. Clone the repository.
2. Navigate to the project folder.

```bash
cd Python_Projects/Random_Joke_Generator
```

3. Run the program.

```bash
python main.py
```
