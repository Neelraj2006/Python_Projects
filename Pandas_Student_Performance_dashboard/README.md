# Pandas Student Performance Dashboard

## Overview

The Pandas Student Performance Dashboard is a beginner-friendly data analysis project built using Python, Pandas, and Matplotlib. The project analyzes student academic records and generates meaningful insights such as topper identification, attendance analysis, grade distribution, performance statistics, and visualizations.

This project was created to strengthen practical understanding of Pandas DataFrames and data analysis workflows.

---

## Features

* Student Data Analysis
* Average Marks Calculation
* Highest and Lowest Marks
* Topper Identification
* Attendance Analysis
* High Performer Detection
* Low Attendance Detection
* Grade Assignment System
* Grade Distribution Analysis
* Student Ranking
* Performance Visualization using Charts

## Project Workflow

1. Create a student dataset.
2. Load data into a Pandas DataFrame.
3. Perform statistical analysis.
4. Identify topper and attendance records.
5. Generate grades automatically.
6. Analyze grade distribution.
7. Sort and rank students.
8. Visualize results using charts.
