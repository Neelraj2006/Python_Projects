# Sales Performance Analyzer

## Overview

Sales Performance Analyzer is a data analysis project built using **Pandas** and **Matplotlib**. It analyzes product sales data, identifies top-performing products, calculates key business statistics, and visualizes insights using charts.

## Features

* Calculate Total Revenue
* Calculate Average Sales
* Identify Highest Selling Product
* Identify Lowest Selling Product
* Find Top 3 Products by Sales
* Rank Products Based on Sales
* Sort Products by Sales
* Generate Sales Visualizations

  * Bar Chart
  * Pie Chart
  * Histogram

## Technologies Used

* Python
* Pandas
* Matplotlib

## Project Output

The project provides:

* Sales Summary Report
* Product Rankings
* Revenue Analysis
* Visual Representation of Sales Data
