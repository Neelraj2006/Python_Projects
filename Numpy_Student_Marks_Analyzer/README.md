# NumPy Student Performance Analyzer

## Overview

The NumPy Student Performance Analyzer is a beginner-friendly data analysis project built using Python, NumPy, and Matplotlib. It analyzes student marks and provides useful insights such as average performance, highest and lowest scores, pass/fail statistics, grade distribution, and graphical visualization.

This project was created to practice NumPy operations and basic data analysis concepts.

---

## Features

* Calculate Average Marks
* Find Highest and Lowest Marks
* Identify the Class Topper
* Display Top 3 Scores
* Pass/Fail Analysis
* Calculate Pass Percentage
* Grade Distribution (A, B, C, D, F)
* Visualize Student Performance using Bar Charts
